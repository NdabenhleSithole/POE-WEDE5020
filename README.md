## Project Overview
This project proposes a five-page SHEIN South Africa website designed to provide users with clear information about SHEIN and its products while providing simple navigation and enquiry functionality.

## Website Goals and Objectives
- Provide accessible product information.
- Improve navigation and user experience.
- Provide an enquiry and contact facility.
- Present SHEIN's products to South African customers.

## Key Features and Functionality
- Homepage with hero image and call-to-action.
- About Us page.
- Products page.
- Enquiry form.
- Contact page.
- Navigation between all pages.

## Part 3 – Enhancing Functionality and SEO

### JavaScript functionality
- Added product search and category filters that work together.
- Added a keyboard-accessible image lightbox for product previews.

### SEO and performance
- Updated page titles and meta descriptions.
- Added Open Graph titles/descriptions, descriptive image alt text and lazy-loaded images.
- Added `robots.txt` and `sitemap.xml` templates.
- Added keyboard focus styling, reduced-motion support and responsive form/product layouts.

### Form limitations
This is a front-end student project. The enquiry form does not check real stock or submit data to a server. The contact form opens an email draft; it does not send automatically. Before using the contact form, replace `replace-with-your-email@example.com` in `js/main.js` with the intended recipient email. Replace the placeholder domain in `sitemap.xml` after deployment. Prices are examples for demonstration and are not official/live prices.
